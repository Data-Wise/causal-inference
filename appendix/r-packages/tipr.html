Introduction

  • tipr performs tipping-point sensitivity analyses for unmeasured confounding: it solves for the strength of a hypothetical confounder that would move an observed estimate to the null (or any chosen reference value). R Causal
  • Key functions covered here
    • tip(), tip_with_binary() – generic continuous / binary confounder engines.
    • Scale-specific wrappers: tip_or(), tip_rr(), tip_hr(), tip_coef() and their _with_binary, _with_r2 variants.
  • Typical use-cases
    • Post-hoc robustness checks for observational studies.
    • Sensitivity reporting in clinical-trial subgroup or per-protocol analyses.
    • Pre-analysis planning (how strong must lurking confounding be to matter?).
  • Benefits vs. alternatives
    • Can target any effect scale (OR, RR, HR, β).
    • Integrates cleanly with broom output pipes and plotting tools (unlike EValue, which returns scalars, or sensemakr, which focuses on partial \(R^2\)).
    • Offers quick grid evaluations useful for interactive dashboards. Journal of Open Source Software

Getting Started

A First “Hello tipr”

effect_adjusted effect_observed exposure_confounder_effect confounder_outcome_effect n_unmeasured_confounders
1 1.5 0.4 2.755676 1

Interpretation: If an unmeasured continuous confounder raised the outcome hazard by the returned HR (≈ 2.8), and was associated with exposure via HR = 0.40, the observed HR would shrink to 1 (no effect).

Scaffold-Yourself Exercise

  1. Change the exposure_confounder_effect to 0.10, 0.20, … 1.00.
  2. Record the required confounder–outcome HR each time.
  3. Plot and describe the trend.

Conceptual Foundations

What Is a “Tipping Point”?

A tipping point is the set of confounder parameters \((\gamma_{UX},\ \gamma_{UY})\) that exactly cancels the bias in an observed effect \(\hat\theta\). Algebraically we solve

\[ \theta_\text{obs} = \theta_\text{true}\times\operatorname{Bias}(\gamma_{UX},\gamma_{UY}), \]

then set \(\theta_\text{true}=1\) (null) and invert. For linear models the bias is additive; for ratio scales it is multiplicative.

DAG Perspective (drawn with dagitty + ggdag)

Nuance: tipr assumes single unmeasured confounder \(U\). Multiple moderate confounders are equivalent to one composite confounder with aggregated effects—a useful but sometimes overlooked approximation.

Key Functions and Features

Below each function appears twice: a basic and an advanced example, followed by tips and contrasts.

1. tip() – Continuous \(U\) on Any Linear-Coefficient Scale

Detailed Explanation

tip() targets estimates on additive scales (e.g., linear-regression coefficients). It requires the observed coefficient and either the exposure–confounder effect or the confounder–outcome effect; it returns the unknown partner.

Syntax

tip(effect_observed, exposure_confounder_effect = NULL,
    confounder_outcome_effect = NULL)

Basic Example – Body-Mass vs. Blood Pressure

effect_adjusted effect_observed exposure_confounder_effect confounder_outcome_effect n_unmeasured_confounders
1 2 0.3 10.07937 1

Advanced Example – High-Dimensional Simulation

effect_adjusted effect_observed exposure_confounder_effect confounder_outcome_effect n_unmeasured_confounders
1 1.522675 -1.884298 0.8 1

Tips, Nuances, Misconceptions

  • Linearity: bias formula derives from linear expectation; use with log-transformed outcomes for skewed data.
  • Common misconception: A large required γ_UY means “safe.” Not necessarily—plausibility depends on domain knowledge.
  • Contrast: sensemakr computes partial \(R^2\) needed; tipr computes effect size directly, often easier to interpret in applied biomedical terms.

2. tip_with_binary() – Binary \(U\)

Detailed Explanation

Adapts Cornfield conditions: specify two of

exposed_confounder_prev, unexposed_confounder_prev, confounder_outcome_effect.

Basic Example – Smoking (U) in Diet-Heart Study

effect_adjusted effect_observed exposed_confounder_prev unexposed_confounder_prev confounder_outcome_effect n_unmeasured_confounders
1 1.4 0.25 0.05 3.222222 1

Advanced Example – Sensitivity Grid

What happens here

  1. possibly()

    safe_tip <- possibly(.f, otherwise = NA_real_)

    Wraps your original anonymous function so that if it ever errors (i.e. the prevalence difference is too small), you quietly get NA_real_ instead of stopping.

  2. map2_dbl()
    Applies safe_tip(exp_prev[i], unexp_prev[i]) for each row and always returns a numeric vector (with NAs where the underlying call failed).

  3. Result
    Your prev_grid$gamma_UY will now be a length-15 numeric vector. Whenever tip_gamma() can’t find a valid confounder (as in your index 16 error), you’ll see an NA there rather than a hard stop.

Nuances & Compare

  • Rare U assumption: When unexposed_confounder_prev≃0, results mimic classical Cornfield inequality.
  • Contrast: EValue provides a single minimal RR needed under equal prevalence—tipr lets prevalences differ, giving richer scenarios.

3. Scale-Specific Wrappers (tip_or(), tip_rr(), tip_hr())

Detailed Explanation

These thin wrappers set default link transformers and interpretation messages. tip_hr() offers an hr_correction argument for common outcomes (>15 %) to adjust the risk-ratio approximation RDocumentation.

Basic Example – Odds Ratio

effect_adjusted effect_observed exposure_confounder_effect confounder_outcome_effect n_unmeasured_confounders
1 2.1 0.3 11.85944 1

Advanced Example – Hazard Ratio with Correction

effect_adjusted effect_observed exposure_confounder_effect confounder_outcome_effect n_unmeasured_confounders
1 1.38397 0.4 2.253288 1

Nuances

  • HR Correction: For cumulative incidences >15 %, hazard ratios diverge from risk ratios—enable hr_correction.
  • Misconception: Setting both exposure_confounder_effect and confounder_outcome_effect will always error; but if both are supplied, the function reports how many such confounders would be needed to tip (nice diagnostic!).

4. Partial \(R^2\) Variants (*_with_r2)

Detailed Explanation

Instead of effect sizes, specify the partial \(R^2\) that \(U\) explains in X and Y. Helpful when domain experts think in %-variance terms.

Example – Robustness Value

effect_adjusted lb_adjusted ub_adjusted effect_observed lb_observed ub_observed se_observed df_observed confounder_exposure_r2 confounder_outcome_r2
0 -0.176947 0.176947 0.25 0.1508014 0.3491986 0.05 100 0.7142857 0.1

Compare vs. sensemakr

sensemakr computes “robustness value” via \(R^2\); tipr adds direct solver so you can toggle between effect-size and variance descriptions seamlessly.

Common Workflows & In-Depth Examples

Basic Workflow (Logistic Regression)

effect_adjusted effect_observed exposure_confounder_effect confounder_outcome_effect n_unmeasured_confounders
1 1.036921 0.2 1.198748 1

Intermediate Workflow – Continuous vs. Binary \(U\) Side-by-Side

  1. Run tip() with realistic continuous \(γ_{UX} = 0.3\).
  2. Run tip_with_binary() under plausible prevalences.
  3. Plot both required \(γ_{UY}\) values to compare robustness.

Advanced Workflow – Interactive Grid + DAG Overlay

Interpret the intersection where plausible \(γ_{UX}\) meets required γ_UY. If intersection lies above typical U effects, the estimate is robust.

Advanced Features & Customization

  • Vectorized calls: pass vectors to effect_observed for batch analyses.
  • Integration: because outputs are numeric, you can feed them into shiny dashboards for real-time robustness sliders.
  • Large datasets: no raw data are needed—only summary estimates—making tipr trivially memory-safe.

Troubleshooting and FAQs

Symptom Diagnosis Fix
“unused argument” Called tip_with_binary without parentheses Add () or ensure all required args
Infinite output Requested impossible combination (e.g., \(γ_{UX} = 0\)) Use realistic non-zero \(γ_{UX}\) or check input order
Negative required effect Swapped sign on exposure_confounder_effect Remember: log-ratio <0 means protective confounder

Best Practices

  • Triangulate: report tipr alongside EValue and sensemakr for convergent credibility.
  • Visualize: always pair numerical tipping points with ggplot curves for interpretability.
  • Document assumptions: specify whether \(γ_{UX}\) refers to log-OR, log-HR, etc.

Conclusion

tipr translates the abstract worry of “unmeasured confounding” into tangible numbers researchers can debate. Use the scaffolded examples above to build from single-scenario checks to fully automated robustness dashboards.
