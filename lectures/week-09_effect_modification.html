Learning Objectives

By the end of this week, students will be able to:

  1. Define effect modification and distinguish it from confounding using formal notation and potential outcomes framework
  2. Compare additive versus multiplicative scales of interaction and explain when each is most appropriate
  3. Differentiate between statistical interaction and mechanistic interaction using Rothman’s sufficient cause framework
  4. Calculate measures of effect modification by hand using simple 2×2 tables and potential outcomes
  5. Implement R code to detect, visualize, and quantify effect modification in observational data
  6. Apply modern causal machine learning methods (causal trees, causal forests) to discover heterogeneous treatment effects
  7. Interpret interaction terms in regression models within a causal framework

1 Comprehensive Topic Explanation

1.1 What is Effect Modification?

Effect modification, also known as treatment effect heterogeneity, occurs when the causal effect of an exposure varies across different levels or values of another variable, called the effect modifier (Hernán & Robins, 2025, Chapter 4). Unlike confounding, which creates bias that must be controlled, effect modification represents genuine biological or social phenomena where treatment effects differ across subgroups.

Formally, let \(V\) be a potential effect modifier. We say that \(V\) modifies the effect of treatment \(A\) on outcome \(Y\) if:

\[ \mathbb{E}[Y^{a=1} - Y^{a=0} \mid V=v] \neq \mathbb{E}[Y^{a=1} - Y^{a=0} \mid V=v'] \]

for some values \(v \neq v'\) of the modifier \(V\).

This definition is inherently causal because it compares potential outcomes within strata of the modifier. Effect modification cannot be definitively established from purely observational associations—it requires the same causal assumptions (exchangeability, positivity, consistency) that we need for identifying any causal effect.

1.2 Scales of Interaction: Additive vs. Multiplicative

The same data can show interaction on one scale but not another, leading to the crucial question: which scale matters?

Additive Scale: Interaction exists if the joint effect differs from the sum of individual effects:

\[ \mathbb{E}[Y^{a=1,v=1}] - \mathbb{E}[Y^{a=0,v=0}] \neq (\mathbb{E}[Y^{a=1,v=0}] - \mathbb{E}[Y^{a=0,v=0}]) + (\mathbb{E}[Y^{a=0,v=1}] - \mathbb{E}[Y^{a=0,v=0}]) \]

Multiplicative Scale: Interaction exists if the joint effect differs from the product of individual relative effects:

\[ \frac{\mathbb{E}[Y^{a=1,v=1}]}{\mathbb{E}[Y^{a=0,v=0}]} \neq \frac{\mathbb{E}[Y^{a=1,v=0}]}{\mathbb{E}[Y^{a=0,v=0}]} \times \frac{\mathbb{E}[Y^{a=0,v=1}]}{\mathbb{E}[Y^{a=0,v=0}]} \]

For rare outcomes, the additive scale is often more relevant for public health because it directly quantifies excess cases attributable to interaction. For common outcomes or when thinking about biological mechanisms, multiplicative interactions may be more natural.

1.3 Statistical vs. Mechanistic Interaction

Statistical interaction refers to departure from additivity (or multiplicativity) in a fitted model. It’s what we observe in regression output when interaction terms are significant.

Mechanistic interaction refers to biological or causal pathways where factors truly work together to produce effects. Rothman’s sufficient cause framework provides the clearest illustration of mechanistic interaction.

1.4 Rothman’s Sufficient Cause Framework

Kenneth Rothman introduced “causal pies” to represent sufficient causes—combinations of factors that, together, inevitably produce the outcome (VanderWeele, 2015, Chapter 1). Each “pie” represents one pathway to disease, with each “slice” representing a component cause.

Synergism occurs when two factors appear as component causes in the same causal pie. For example:

  • Pie 1: {Smoking, Asbestos exposure, Genetic susceptibility} → Lung cancer
  • Pie 2: {Heavy alcohol use, Hepatitis B, Poor nutrition} → Liver disease

If smoking and asbestos appear together in Pie 1 but neither appears in other pies, they exhibit synergistic interaction.

This framework explains why:

  • Interaction can exist on the additive scale even when multiplicative interaction is absent
  • Mechanistic interaction may not always manifest as statistical interaction
  • The “background” prevalence of other component causes affects observed interaction patterns

Visualizing Rothman’s Sufficient Cause Model

Explanation Of the Graphic

This graphic perfectly illustrates the key concepts:

  1. Multiple Sufficient Causes: There are three distinct causal pathways (Pie I, II, and III) that can lead to the outcome.
  2. Component Causes: Each slice (A, B, C, etc.) is a component cause. Notice that Pie III has four component causes, while the others have three, showing that the number of components required to complete a mechanism can vary.
  3. Interaction: In Pie I, component causes A, B, and C interact. If an individual has A and C, the addition of B completes the pie and causes the disease. This is a mechanistic interaction.
  4. No Necessary Cause: In this specific example, there is no single component cause that appears in all three pies, so there is no necessary cause shown. If “A” were also a slice in Pie III, it would be a necessary cause for this disease.

This type of visualization is incredibly useful for teaching, for clarifying your own thinking about a research problem, and for communicating complex causal ideas to a broader audience.

1.5 Causal Interaction with Multiple Treatments

When we have two treatments \(A\) and \(B\), we can define four potential outcomes for each individual:

  • \(Y^{a=0,b=0}\): Neither treatment
  • \(Y^{a=1,b=0}\): Only treatment A
  • \(Y^{a=0,b=1}\): Only treatment B
  • \(Y^{a=1,b=1}\): Both treatments

Additive causal interaction exists when:

\[ \mathbb{E}[Y^{a=1,b=1} - Y^{a=0,b=0}] \neq (\mathbb{E}[Y^{a=1,b=0} - Y^{a=0,b=0}] + \mathbb{E}[Y^{a=0,b=1} - Y^{a=0,b=0}]) \]

The left side represents the joint effect, while the right side represents the sum of marginal effects.

1.6 Modern Causal Machine Learning Approaches

Traditional approaches to effect modification require a priori specification of interaction terms. Modern causal machine learning methods can discover heterogeneous treatment effects without pre-specifying interactions.

Causal Trees: Recursive partitioning that splits on covariates to maximize treatment effect heterogeneity rather than outcome prediction (Athey & Imbens, 2016).

Causal Forests: An ensemble method that averages many causal trees, providing both point estimates and uncertainty quantification for heterogeneous treatment effects (Wager & Athey, 2018).

These methods are particularly valuable when:

  • The modifier space is high-dimensional
  • Interactions involve multiple variables simultaneously
  • The functional form of modification is unknown

2 Intuitive Clarifications of Challenging Ideas

Tip🧠 Learning Tip: The Interaction Paradox

Analogy: Think of effect modification like cooking. Salt enhances the flavor of tomatoes more than it enhances the flavor of ice cream. The “effect” of salt depends on what you’re adding it to—this is effect modification.

However, whether we measure this on a “taste intensity” scale (additive) or a “flavor multiplication” scale (multiplicative) can lead to different conclusions about whether interaction exists.

2.1 Why Confounding ≠ Effect Modification

Common Misconception: “If a variable is associated with both treatment and outcome, it’s a confounder.”

Reality: Effect modifiers can be associated with treatment and outcome WITHOUT being confounders. The key difference:

  • Confounder: Creates bias in the marginal treatment effect
  • Effect Modifier: Changes the treatment effect across strata, but each stratum-specific effect may be unbiased

Visual Metaphor: Think of confounding as wearing tinted glasses that distort ALL colors equally. Effect modification is like having different lighting in different rooms—the same object looks different in each room, but you’re seeing it clearly in each context.

2.2 The Scale Dependence Problem

Consider these data:

Group Risk with Treatment Risk without Treatment Risk Difference Risk Ratio
Men 0.20 0.10 0.10 2.0
Women 0.15 0.05 0.10 3.0
  • Additive scale: No interaction (both differences = 0.10)
  • Multiplicative scale: Strong interaction (ratios = 2.0 vs 3.0)

Intuition: This happens because the baseline risks differ between men and women. When baseline risk is lower, the same absolute increase represents a larger relative increase.

2.3 Why Sufficient Causes Matter

Mechanical Analogy: Think of disease as a car failing to start. There might be multiple ways for the car to fail:

  • Path 1: {Dead battery} + {Cold weather} + {Old alternator}
  • Path 2: {Empty gas tank} + {Clogged fuel filter}
  • Path 3: {Faulty starter} + {Corroded connections}

If “cold weather” and “dead battery” appear together in Path 1, they’re synergistic—cold weather only matters when you also have a dead battery problem.

This explains why some interactions only appear in certain populations or contexts.

3 Simple, Hand-Calculation Numerical Example

Let’s work through a complete example calculating effect modification by hand.

✅ Worked Example: Drug Efficacy by Age Group

Scenario: A new antihypertensive drug is tested. We want to know if age modifies its effect.

Data:

Age Group Treatment n Mean BP Reduction
Young (<50) Drug 100 15 mmHg
Young (<50) Placebo 100 3 mmHg
Old (≥50) Drug 100 20 mmHg
Old (≥50) Placebo 100 8 mmHg

Step 1: Calculate stratum-specific effects

Young group effect: \(15 - 3 = 12\) mmHg reduction

Old group effect: \(20 - 8 = 12\) mmHg reduction

Step 2: Test for effect modification

Since both effects equal 12 mmHg, there is no effect modification on the additive scale.

Step 3: Check multiplicative scale

Young group ratio: \(15/3 = 5.0\)

Old group ratio: \(20/8 = 2.5\)

Since \(5.0 \neq 2.5\), there is effect modification on the multiplicative scale.

Interpretation: The drug provides the same absolute benefit (12 mmHg) regardless of age, but represents a larger relative improvement in younger patients due to their lower baseline response to placebo.

Hand Calculation: Sufficient Cause Framework

Scenario: Consider lung cancer with two exposures: smoking (S) and asbestos (A).

Assume three sufficient cause “pies”:

  • Pie 1: {S, A, U₁} (smoking + asbestos + unknown factors)
  • Pie 2: {S, U₂, U₃} (smoking + other unknown factors)
  • Pie 3: {U₄, U₅, U₆} (non-smoking causes)

Population prevalences:

  • S: 30%, A: 10%, U₁: 5%, U₂: 2%, U₃: 40%, U₄: 1%, U₅: 20%, U₆: 30%

Step 1: Calculate disease probabilities

\[ \begin{aligned} \pr{\text{Disease} \mid S=1, A=1} & = \pr{\text{Pie 1} \lor \text{Pie 2}} \\ & = \pr{\text{Pie 1}} + \pr{\text{Pie 2}} - \pr{\text{Pie 1} \land \text{Pie 2}} \\ & = \pr{U₁=1} + \pr{U₂=1 \land U₃=1} - \pr{U₁=1 \land U₂=1 \land U₃=1} \\ & = 0.05 + (0.02×0.40) - (0.05×0.02×0.40) \\ & = 0.05 + 0.008 - 0.0004 \\ & = 0.0576 \end{aligned} \tag{1}\]

\[ \pr{\text{Disease} \mid S=1, A=0} = \pr{\text{Pie 2}} = \pr{U₂=1 \land U₃=1} = 0.02 \times 0.40 = 0.008 \]

\[ \pr{\text{Disease} \mid S=0, A=1} = \pr{\text{Pie 3}} = \pr{U₄=1 \land U₅=1 \land U₆=1} = 0.01 \times 0.20 \times 0.30 = 0.0006 \]

\[ \pr{\text{Disease} \mid S=0, A=0} = \pr{\text{Pie 3}} = 0.0006 \]

Step 2: Calculate interaction measures

Joint effect: 0.0576 - 0.0006 = 0.057

Smoking alone: 0.008 - 0.0006 = 0.0074

Asbestos alone: 0.0006 - 0.0006 = 0

Sum of individual effects: 0.0074 + 0 = 0.0074

Synergy index: (0.057 - 0.0074)/0.0074 = 6.7

This indicates strong synergistic interaction—the combined effect is nearly 7 times larger than expected from adding individual effects.

4.1 Simulating Effect Modification Data

# Set seed for reproducibility
set.seed(12345)

# Simulate data with age-dependent treatment effect
n <- 1000
age <- rnorm(n, mean = 50, sd = 15)
age_centered <- age - 50

# Treatment assignment (slightly more likely for older patients)
treatment <- rbinom(n, 1, prob = 0.4 + 0.001 * age_centered)

# Outcome with effect modification
# Base outcome depends on age
# Treatment effect is stronger in older patients
baseline_outcome <- 120 + 0.5 * age_centered + rnorm(n, 0, 10)
treatment_effect <- -10 - 0.2 * age_centered # Stronger effect in older patients
outcome <- baseline_outcome + treatment * treatment_effect

# Create dataset
sim_data <- tibble(
  id = 1:n,
  age = age,
  age_group = ifelse(age >= 50, "Older", "Younger"),
  treatment = factor(treatment, labels = c("Control", "Treatment")),
  outcome = outcome
)

4.4 Calculating Stratum-Specific Effects

Code 
# Calculate effects within age strata
stratum_effects <- sim_data |>
  group_by(age_group) |>
  summarise(
    control_mean = mean(outcome[treatment == "Control"]),
    treatment_mean = mean(outcome[treatment == "Treatment"]),
    effect = treatment_mean - control_mean,
    se = sqrt(
      var(outcome[treatment == "Control"]) /
        sum(treatment == "Control") +
        var(outcome[treatment == "Treatment"]) /
          sum(treatment == "Treatment")
    ),
    ci_lower = effect - 1.96 * se,
    ci_upper = effect + 1.96 * se,
    .groups = "drop"
  )

stratum_effects |>
  kable(
    digits = 2,
    col.names = c(
      "Age Group",
      "Control Mean",
      "Treatment Mean",
      "Effect",
      "SE",
      "95% CI Lower",
      "95% CI Upper"
    ),
    caption = "Treatment Effects by Age Stratum"
  ) |>
  kable_styling(bootstrap_options = "striped")

Interpretation: The treatment reduces blood pressure by 8.2 mmHg in younger patients but by 10.58 mmHg in older patients—clear evidence of effect modification.

4.6 Using Marginal Effects for Interpretation

Code 
# Calculate marginal effects at specific age values
ages_of_interest <- c(30, 45, 60, 75)

marginal_effects <- marginaleffects::predictions(
  model_with_int,
  newdata = expand_grid(
    treatment = c("Control", "Treatment"),
    age = ages_of_interest
  )
) |>
  select(treatment, age, estimate, conf.low, conf.high) |>
  pivot_wider(
    names_from = treatment,
    values_from = c(estimate, conf.low, conf.high)
  ) |>
  mutate(
    effect = estimate_Treatment - estimate_Control,
    effect_se = sqrt(
      (conf.high_Treatment - conf.low_Treatment)^2 /
        16 +
        (conf.high_Control - conf.low_Control)^2 / 16
    ),
    effect_ci_low = effect - 1.96 * effect_se,
    effect_ci_high = effect + 1.96 * effect_se
  ) |>
  select(age, effect, effect_ci_low, effect_ci_high)

marginal_effects |>
  kable(
    digits = 2,
    col.names = c(
      "Age",
      "Treatment Effect",
      "95% CI Lower",
      "95% CI Upper"
    )
  )

Lab Dataset: Cardiovascular Drug Trial

Code 
set.seed(42)
n_lab <- 2000

# Generate patient characteristics
lab_data <- tibble(
  patient_id = 1:n_lab,
  age = round(rnorm(n_lab, 65, 12)),
  sex = sample(c("Male", "Female"), n_lab, replace = TRUE),
  baseline_risk = case_when(
    sex == "Male" & age >= 65 ~ 0.15,
    sex == "Male" & age < 65 ~ 0.08,
    sex == "Female" & age >= 65 ~ 0.10,
    sex == "Female" & age < 65 ~ 0.05
  ),
  # Treatment assignment (slightly biased toward higher risk patients)
  treatment = rbinom(n_lab, 1, prob = 0.5 + 0.1 * (baseline_risk - 0.1)),
  # Generate outcome with complex interactions
  # Drug effect varies by sex and age
  drug_effect = case_when(
    treatment == 1 & sex == "Male" ~ -0.6 * baseline_risk,
    treatment == 1 & sex == "Female" ~ -0.8 * baseline_risk,
    TRUE ~ 0
  )
) |>
  # FIX: Create a valid probability vector first
  mutate(
    # Calculate the event probability, including noise
    event_prob = baseline_risk + drug_effect + rnorm(n_lab, 0, 0.01),
    # CRITICAL: Clamp the probability to the valid [0, 1] range
    event_prob = pmax(0, pmin(1, event_prob)),
    # Now, simulate the outcome using the sanitized probability
    cv_event = rbinom(n_lab, 1, prob = event_prob)
  ) |>
  # Convert treatment to a factor for clarity in models/plots
  mutate(
    treatment = factor(treatment, labels = c("Placebo", "Drug")),
    age_group = ifelse(age >= 65, "≥65", "<65")
  )

# Display summary
lab_data |>

  head(10) |>
  kable(caption = "Lab Dataset: Cardiovascular Drug Trial") |>

6 Common Pitfalls & Checks

WarningCommon Pitfall: Confusing Effect Modification with Confounding

The Problem: Students often think that any variable associated with both treatment and outcome must be a confounder that needs to be “controlled for.”

The Reality: Effect modifiers can be associated with treatment and outcome without creating bias. In fact, stratifying by an effect modifier is often exactly what we want to do.

Check: Ask yourself: “Am I trying to get an unbiased estimate of the average treatment effect, or am I trying to understand how treatment effects vary across groups?”

WarningCommon Pitfall: Scale Confusion

The Problem: Reporting interaction on only one scale without considering whether it’s the most meaningful scale.

The Check:

  • For rare outcomes (< 10%): Additive scale often more meaningful
  • For common outcomes: Consider both scales
  • For mechanistic understanding: Multiplicative scale may be more natural
  • For public health impact: Additive scale shows attributable cases

Red Flag: Saying “there’s no interaction” when you’ve only checked one scale.

WarningCommon Pitfall: Statistical vs. Biological Interaction

The Problem: Assuming that statistical interaction (significant interaction term) equals biological interaction (synergistic mechanisms).

The Reality:

  • Statistical interaction can exist without biological synergism
  • Biological synergism might not manifest as statistical interaction due to power issues
  • The sufficient cause framework helps distinguish these concepts

Check: Always interpret statistical findings within a biological/mechanistic context.

ImportantEssential Checks for Effect Modification Analysis
  1. Sample Size: Do you have adequate power to detect interactions? Interaction tests typically need 4x the sample size of main effect tests.
  2. Multiple Comparisons: Are you testing many potential modifiers? Consider adjustment for multiple testing.
  3. Clinical Significance: Is the size of effect modification clinically meaningful, not just statistically significant?
  4. Biological Plausibility: Does the observed interaction make biological sense?
  5. Consistency: Is the interaction consistent across different measures and analytical approaches?
TipSelf-Check Questions

Before concluding your analysis, ask:

  • Have I considered effect modification on both additive and multiplicative scales?
  • Do my findings make biological/mechanistic sense?
  • Could this apparent interaction be due to confounding within strata?
  • Are there other variables that might modify this relationship?
  • How would I explain these findings to a clinician or policy maker?

8 Appendix: Advanced Theory & Derivations

8.1 Mathematical Framework for Effect Modification

Let \(Y^a\) denote the potential outcome under treatment level \(a\), and let \(V\) be a potential effect modifier. The individual treatment effect for person \(i\) with modifier value \(V_i = v\) is:

\(\Delta_i(v) = Y_i^{a=1} - Y_i^{a=0} \mid V_i = v\)

Population-level effect modification exists when: \(\mathbb{E}[\Delta_i(v)] \neq \mathbb{E}[\Delta_i(v')]\) for some \(v \neq v'\).

Formal Definition of Additive Interaction between treatments \(A\) and \(B\): \(SI = \frac{\mathbb{E}[Y^{a=1,b=1}] - \mathbb{E}[Y^{a=0,b=0}] - (\mathbb{E}[Y^{a=1,b=0}] - \mathbb{E}[Y^{a=0,b=0}]) - (\mathbb{E}[Y^{a=0,b=1}] - \mathbb{E}[Y^{a=0,b=0}])}{\mathbb{E}[Y^{a=1,b=0}] - \mathbb{E}[Y^{a=0,b=0}] + \mathbb{E}[Y^{a=0,b=1}] - \mathbb{E}[Y^{a=0,b=0}]}\)

where \(SI > 0\) indicates positive (synergistic) interaction, \(SI = 0\) indicates additivity, and \(SI < 0\) indicates negative (antagonistic) interaction.

8.2 Sufficient Cause Theory: Mathematical Treatment

Following Rothman’s framework, let \(S_k\) represent the \(k\)-th sufficient cause (causal pie). Each sufficient cause is a minimal set of component causes that, when all present, inevitably produce the outcome.

If we have \(K\) sufficient causes, the probability of disease is:

\(P(D = 1) = P\left(\bigcup_{k=1}^K S_k\right)\)

Theorem: Two factors \(A\) and \(B\) exhibit positive additive interaction if and only if they appear together as component causes in at least one sufficient cause.

Proof Sketch:

  • If \(A\) and \(B\) appear together in \(S_1\) but separately in other sufficient causes, then \(P(D|A=1,B=1)\) includes all pathways involving \(S_1\) plus individual pathways
  • This creates a “bonus” effect beyond what would be expected from adding individual contributions
  • Mathematically, this manifests as positive deviation from additivity

Numerical Illustration: Suppose:

  • \(S_1 = \{A, B, U_1\}\) with \(P(U_1 = 1) = 0.1\)
  • \(S_2 = \{A, U_2, U_3\}\) with \(P(U_2 = 1) = 0.05\), \(P(U_3 = 1) = 0.4\)
  • \(S_3 = \{B, U_4, U_5\}\) with \(P(U_4 = 1) = 0.02\), \(P(U_5 = 1) = 0.6\)
  • All \(U_i\) are independent

Then:

\(P(D | A=1, B=1) = P(S_1 \cup S_2 \cup S_3) = 0.1 + 0.05 \times 0.4 + 0.02 \times 0.6 - \text{overlap terms}\)

Computing exactly:

\(P(D | A=1, B=1) = 0.1 + 0.02 + 0.012 - 0.1 \times 0.02 - 0.1 \times 0.012 - 0.02 \times 0.012 + 0.1 \times 0.02 \times 0.012\)

\(= 0.132 - 0.002 - 0.0012 - 0.00024 + 0.000024 = 0.128976\)

Similarly:

\(P(D | A=1, B=0) = 0.05 \times 0.4 = 0.02\)

\(P(D | A=0, B=1) = 0.02 \times 0.6 = 0.012\)

\(P(D | A=0, B=0) = 0\)

Interaction measures:

  • Joint effect: \(0.128976 - 0 = 0.128976\)
  • Sum of individual effects: \(0.02 + 0.012 = 0.032\)
  • Synergy index: \(\frac{0.128976 - 0.032}{0.032} = 3.03\)

8.3 Causal Machine Learning: Theoretical Foundations

Causal Trees: The splitting criterion maximizes treatment effect heterogeneity rather than outcome prediction. At each node, we choose the split that maximizes:

\(\Delta(\text{split}) = \frac{n_L n_R}{(n_L + n_R)^2} \times (\hat{\tau}_L - \hat{\tau}_R)^2\)

where \(\hat{\tau}_L\) and \(\hat{\tau}_R\) are estimated treatment effects in left and right child nodes, and \(n_L\), \(n_R\) are sample sizes.

Causal Forests: Average predictions across many causal trees, with each tree trained on a subsample. The final estimate is:

\(\hat{\tau}(x) = \frac{1}{B} \sum_{b=1}^B \hat{\tau}_b(x)\)

Theoretical Guarantee: Under regularity conditions, causal forest estimates are asymptotically normal: \(\sqrt{n}(\hat{\tau}(x) - \tau(x)) \xrightarrow{d} \mathcal{N}(0, \sigma^2(x))\)

where \(\sigma^2(x)\) can be estimated using the infinitesimal jackknife.

Numerical Illustration: Consider a simple case with binary modifier \(X \in \{0,1\}\): - True effects: \(\tau(0) = -5\), \(\tau(1) = -15\) - Sample sizes: \(n_0 = n_1 = 500\) - Noise level: \(\sigma = 10\)

A single causal tree might estimate:

  • \(\hat{\tau}(0) = -4.8 \pm 0.63\)
  • \(\hat{\tau}(1) = -14.2 \pm 0.63\)

A causal forest with 1000 trees would provide:

  • \(\hat{\tau}(0) = -5.02 \pm 0.45\)
  • \(\hat{\tau}(1) = -14.98 \pm 0.45\)

The forest estimate is closer to the truth with smaller standard errors due to variance reduction from averaging.

8.4 Advanced DAG Theory for Effect Modification

Theorem: In a DAG, variable \(V\) is an effect modifier (but not a confounder) for the effect of \(A\) on \(Y\) if and only if: 1. There exists a directed path from \(V\) to \(Y\) that includes an edge into a collider on a causal path from \(A\) to \(Y\), OR 2. \(V\) is a parent of \(Y\) and there is no backdoor path from \(A\) to \(Y\) through \(V\)

Numerical Example: Consider the DAG: \(A \rightarrow M \leftarrow V \rightarrow Y \leftarrow A\)

With linear relationships:

  • \(M = 2A + 3V + \varepsilon_M\)
  • \(Y = A + V + 4M + \varepsilon_Y\)

The total effect of \(A\) on \(Y\) is:

\(\frac{\partial Y}{\partial A} = 1 + 4 \times 2 = 9\)

But this effect is modified by \(V\) through the collider \(M\). When \(V\) is large, \(M\) tends to be large, amplifying the indirect effect \(A \rightarrow M \rightarrow Y\).

Stratified effects: - When \(V = 0\): Effect of \(A\) ≈ \(1 + 4 \times 2 = 9\) - When \(V = 10\): Effect of \(A\) ≈ \(1 + 4 \times 2 = 9\) (same total effect) - But the mechanism differs: more flows through the \(A \rightarrow M \rightarrow Y\) pathway when \(V\) is large

This illustrates that effect modification can be mechanistic even when the total causal effect remains constant across strata.

Effect Modification vs. Interaction: Causal Inference Perspective

Core Distinction

Aspect Effect Modification Interaction
Definition Heterogeneity of treatment effect across subgroups (Hernán & Robins, §12.3) Non-additivity/non-multiplicativity of joint effects of two+ exposures (VanderWeele, 2009)
Causal Role Modifier (M) is pre-treatment (e.g., age, sex) All variables are treatments of interest (e.g., drug A + drug B)
Focus “For whom does the treatment work?” “Do combined exposures amplify/reduce effects?”
Notation \(\E{Y^a \mid M=1} - \E{Y^a \mid M=0} \neq 0\) \(\E{Y^{a=1,b=1}} \neq \E{Y^{a=1,b=0}} + \E{Y^{a=0,b=1}} - \E{Y^{a=0,b=0}}\)

Key Similarities

  1. Statistical Testing Both use regression with product terms (e.g., Y ~ A*M).
  2. Scale Dependence Additive/multiplicative interaction can exist independently (e.g., RERI ≠ 0 but RR11/(RR10×RR01) = 1).
  3. Biological Interpretation Both imply mechanistic synergy (e.g., Rothman’s pies).

Critical Differences

Feature Effect Modification Interaction
Symmetry Asymmetric: M modifies A’s effect, but not vice versa Symmetric: A and B equally “interact”
Design Implication Stratified analysis or subgroup-specific estimates Requires joint intervention (e.g., 2×2 factorial trial)
Sufficient Cause Not required Implies component causes in same pie (Rothman, 1976)
Example Aspirin reduces MI risk only in men (M = sex) Smoking + asbestos cause lung cancer only when both present

Illustrative Example

Data: - Treatment \(A\): Statin (1=yes, 0=no) - Modifier \(M\): Diabetes (1=yes, 0=no) - Outcome \(Y\): LDL reduction (mg/dL)

Group \(\E{Y^{a=1} \mid M}\) \(\E{Y^{a=0} \mid M}\) Effect \(\tau_M\)
Non-diabetic (\(M=0\)) -40 -5 -35
Diabetic (\(M=1\)) -50 -10 -40
  • Effect Modification: \(\tau_{M=1} - \tau_{M=0} = -5\) (stronger effect in diabetics)
  • Interaction (if \(M\) were a treatment): \(\underbrace{\E{Y^{11}}}_{\text{-50}} - \underbrace{\E{Y^{00}}}_{\text{-5}} \neq (\underbrace{\E{Y^{10}}}_{\text{-40}} - \underbrace{\E{Y^{00}}}_{\text{-5}}) + (\underbrace{\E{Y^{01}}}_{\text{-10}} - \underbrace{\E{Y^{00}}}_{\text{-5}})\) → \(-45 \neq (-35) + (-5) = -40\) (additive interaction present)

Why The Confusion?

  1. Same statistical model (e.g., GLM with product term) tests both.
  2. Colloquial overlap: “Interaction” often misused for subgroup effects.
  3. Scale-specific results: A variable can be modifier on additive scale but not multiplicative.

Rule of thumb: If the second variable is not manipulable (e.g., sex, genetics), it’s effect modification. If both can be assigned (e.g., drug A + drug B), it’s interaction (Neal, 2020, §8.4).

Advanced Insight: Sufficient Cause Framework

  • Effect modification: No requirement for shared causal mechanisms.
  • Interaction: Implies \(A\) and \(B\) are component causes in the same sufficient cause: \(Y^{a=1,b=1} = 1\) but \(Y^{a=1,b=0} = Y^{a=0,b=1} = 0\) for some individuals. (VanderWeele & Robins, 2007, Journal of Machine Learning Research)
