Overview

This module introduces Inverse Probability (IP) weighting and Marginal Structural Models (MSMs) as fundamental approaches for estimating causal effects from observational data. Unlike stratification and outcome regression which we’ve studied previously, IP weighting creates a “pseudo-population” where treatment assignment becomes independent of measured confounders, allowing us to estimate causal effects by fitting simple associational models.

We’ll explore this methodology using the motivating example of estimating the causal effect of smoking cessation on body weight gain using data from the National Health and Nutrition Examination Survey Data I Epidemiologic Follow-up Study (NHEFS). This real-world application demonstrates how IP weighting handles high-dimensional confounding and extends to complex scenarios involving continuous treatments, effect modification, and missing data.

The connection to marginal structural models provides a formal framework for understanding counterfactual outcomes and enables us to move beyond simple dichotomous treatments to more complex dose-response relationships.

Learning Objectives

By the end of this module, students will be able to:

  1. Explain the conceptual foundation of IP weighting and how it creates a pseudo-population for causal inference (Knowledge/Comprehension)
  2. Distinguish between nonstabilized and stabilized IP weights, identifying when each is appropriate and computing both by hand for simple examples (Analysis)
  3. Construct and interpret marginal structural models for both dichotomous and continuous treatments, connecting model parameters to causal estimands (Application/Analysis)
  4. Implement IP weighting estimation in R using dagitty, ggdag, and appropriate modeling functions, including diagnostic checks for positivity violations (Application)
  5. Evaluate the assumptions required for valid IP weighting (exchangeability, positivity, consistency) and identify potential violations in real datasets (Evaluation)
  6. Design and execute a complete IP weighting analysis including confounder selection, model specification, weight estimation, and sensitivity analysis (Synthesis)

Comprehensive Topic Explanation

The Fundamental Challenge

Observational data presents a persistent challenge: treatments are not randomly assigned. Instead, treatment assignment depends on observed and unobserved characteristics that may also influence the outcome. This creates confounding - a mixing of the causal effect we want to estimate with selection effects that bias our estimates.

Consider our motivating example: we want to estimate the causal effect of smoking cessation on weight gain using NHEFS data. Simply comparing mean weight gain between quitters and non-quitters gives us:

  • Quitters: \(\Ehat{Y|A=1} = 4.5\) kg
  • Non-quitters: \(\Ehat{Y|A=0} = 2.0\) kg
  • Naive difference: \(4.5 - 2.0 = 2.5\) kg

But this associational difference \(\E{Y|A=1} - \E{Y|A=0}\) is not the causal difference \(\E{Y^{a=1}} - \E{Y^{a=0}}\) we seek, because quitters and non-quitters differ systematically in characteristics that affect weight gain (Hernán & Robins, 2020).

IP Weighting: The Core Intuition

IP weighting addresses confounding by creating a pseudo-population where treatment assignment is independent of measured confounders. The key insight is to weight each individual by the inverse probability of receiving the treatment they actually received.

For individual \(i\) with treatment \(A_i\) and confounders \(L_i\), the IP weight is:

\[ W_i^A = \frac{1}{f(A_i|L_i)} \tag{1}\]

where \(f(A_i|L_i)\) is the conditional probability (or density) of receiving treatment \(A_i\) given confounders \(L_i\).

Why Does This Work?

In the weighted pseudo-population, individuals who received an unlikely treatment (given their confounders) are up-weighted, while those who received a likely treatment are down-weighted. This rebalancing creates a population where:

  1. Treatment assignment is independent of confounders: \(A \indep L\)
  2. The standardized mean equals the counterfactual mean: \(\ESub{ps}{Y|A=a} = \E{Y^a}\)
  3. Association equals causation: We can estimate causal effects using simple associational models

Mathematical Foundation

The pseudo-population has two crucial properties (Hernán & Robins, 2020):

Property 1 (Independence): In the pseudo-population, \(A \indep L\).

Property 2 (Preservation of Counterfactual Means):

\[ \ESub{ps}{Y|A=a} = \sum_l \E{Y|A=a, L=l} \prob{L=l} = \E{Y^a} \tag{2}\]

The second equality holds under conditional exchangeability \(Y^a \indep A | L\).

From Nonstabilized to Stabilized Weights

The basic IP weights \(W^A = 1/f(A|L)\) are called nonstabilized weights. While they create the desired pseudo-population, they can have high variability, leading to inefficient estimates.

Stabilized weights address this by including the marginal treatment probability in the numerator:

\[ SW^A = \frac{f(A)}{f(A|L)} \tag{3}\]

where \(f(A)\) is the marginal probability of treatment.

For dichotomous treatment:

  • Treated individuals: \(SW^A = \frac{\prob{A=1}}{\prob{A=1|L}}\)
  • Untreated individuals: \(SW^A = \frac{\prob{A=0}}{\prob{A=0|L}}\)

Stabilized weights preserve the causal interpretation while typically yielding more efficient estimates, especially in complex models.

Extension to Marginal Structural Models

A marginal structural model specifies the relationship between treatment and counterfactual outcomes:

\[ \E{Y^a} = g(a; \boldsymbol{\beta}) \tag{4}\]

where \(g(\cdot)\) is a known function (e.g., linear, logistic) and \(\boldsymbol{\beta}\) are parameters to be estimated.

For example, a linear MSM for dichotomous treatment:

\[ \E{Y^a} = \beta_0 + \beta_1 a \]

Here, \(\beta_1 = \E{Y^{a=1}} - \E{Y^{a=0}}\) is the average causal effect.

The key insight is that parameters of the MSM can be estimated by fitting the corresponding associational model to the IP-weighted pseudo-population:

\[ \E{Y|A} = \theta_0 + \theta_1 A \]

Under our assumptions, \(\hat{\theta}_1\) provides a consistent estimate of \(\beta_1\).

Handling Complex Treatments

Continuous Treatments

For continuous treatments, IP weights require estimating probability density functions rather than probabilities. This typically involves assuming a distributional form (e.g., normal) and estimating parameters:

\[ f(A|L) \sim N(\mu_L, \sigma^2) \]

where \(\mu_L = \E{A|L}\) and \(\sigma^2\) are estimated via regression.

Polytomous Treatments

For treatments with multiple categories, we use multinomial models to estimate \(\prob{A=a|L}\) for each treatment level \(a\).

Assumptions for Valid Inference

IP weighting requires the same fundamental assumptions as other causal inference methods:

  1. Exchangeability: \(Y^a \indep A | L\) (no unmeasured confounding)
  2. Positivity: \(0 < \prob{A=a|L=l} < 1\) for all relevant \((a,l)\)
  3. Consistency: \(Y_i = Y_i^{a_i}\) when \(A_i = a_i\)

Additionally, we need:

  1. Correct model specification for the propensity score \(f(A|L)\)

Violations of positivity are particularly problematic for IP weighting, as they lead to extreme weights and unstable estimates.

Advantages and Limitations

Advantages:

  • Separates design (weight estimation) from analysis phases
  • Natural extension to time-varying treatments
  • Transparent handling of effect modification
  • Robust to outcome model misspecification

Limitations:

  • Sensitive to positivity violations
  • Requires correct propensity score model
  • Can be inefficient with extreme weights
  • Challenging for continuous treatments

Intuitive Clarifications of Challenging Ideas

The Pseudo-Population Metaphor

Think of IP weighting as creating a hypothetical randomized experiment. In this imaginary study:

  • Everyone has the same probability of receiving each treatment level
  • We’ve “removed the arrows” from confounders to treatment in our causal diagram
  • The treatment assignment mechanism is now random rather than systematic
TipVisualization Aid

Imagine we have 1000 people in our original study. After IP weighting, we might have an effective sample size that looks like 2000 people, but these aren’t “new” people—they’re weighted copies that rebalance the original sample to look like what we’d get from random assignment.

Why “Inverse” Probability?

The term “inverse probability” often confuses students. Here’s the intuition:

  • If someone has a high probability of receiving their observed treatment, they represent many similar people → low weight (down-weight the common case)
  • If someone has a low probability of receiving their observed treatment, they represent few similar people → high weight (up-weight the rare case)

Example: Consider a smoker who quits despite having characteristics that typically predict continued smoking. This person gets a high weight because they represent the many similar smokers who didn’t quit but would have gained weight if they had.

The Stabilization Concept

Think of stabilized weights as variance control:

  • Nonstabilized weights: \(1/\prob{\text{treatment}|\text{confounders}}\)
  • Stabilized weights: \(\prob{\text{treatment}}/\prob{\text{treatment}|\text{confounders}}\)

The numerator acts as a stabilizing factor that prevents weights from becoming too extreme while preserving the causal interpretation.

ImportantKey Insight: Stabilization Preserves the Population

Stabilized weights maintain the original population size in expectation: \(\E{SW^A} = 1\). This means our effective sample size stays approximately the same, unlike nonstabilized weights where \(\E{W^A} > 1\).

Marginal Vs Conditional Models

A common source of confusion is the distinction between marginal structural models and conditional models:

  • Conditional model: \(\E{Y|A, L} = \alpha_0 + \alpha_1 A + \alpha_2^T L\)
    • Includes confounders as covariates
    • \(\alpha_1\) is the effect adjusting for \(L\)
  • Marginal structural model: \(\E{Y^a} = \beta_0 + \beta_1 a\)
    • No confounders in the model
    • \(\beta_1\) is the marginal (population-average) causal effect

The MSM gives us the effect we’d see if we intervened on the entire population, while the conditional model gives us the effect within strata of \(L\). This is a key distinction.

Common Misconceptions

WarningMisconception 1: “IP Weighting Eliminates confounding”

Reality: IP weighting creates a pseudo-population where confounding is absent, but this depends on measuring all relevant confounders and correct model specification.

WarningMisconception 2: “Heavier Weights Are Always better”

Reality: Extreme weights often indicate positivity violations or model misspecification. Weights should be examined for reasonableness.

WarningMisconception 3: “Stabilized Weights Are Always preferred”

Reality: For saturated models (like simple dichotomous treatment), stabilized and nonstabilized weights yield identical point estimates. Stabilized weights primarily help with efficiency in complex models.

Simple, Hand-Calculation Numerical Example(s)

Let’s work through IP weighting with a minimal example to build intuition.

Worked Example: Smoking and Weight Gain

Consider 6 individuals with data on:

  • \(A\): Quit smoking (1=yes, 0=no)
  • \(Y\): Weight gain (kg)
  • \(L\): Age group (1=older, 0=younger)
Person \(L\) (Age) \(A\) (Quit) \(Y\) (Weight)
1 0 0 1
2 0 1 4
3 1 0 2
4 1 0 1
5 1 1 3
6 1 1 5

Step 1: Calculate Crude Association

\[ \Ehat{Y|A=1} = \frac{4+3+5}{3} = 4.0 \text{ kg} \]

\[ \Ehat{Y|A=0} = \frac{1+2+1}{3} = 1.33 \text{ kg} \]

\[ \text{Crude difference} = 4.0 - 1.33 = 2.67 \text{ kg} \]

Step 2: Estimate Propensity Scores

Calculate \(\ProbHat{A=1|L=l}\) for each age group:

  • Younger (\(L=0\)): 1 quit out of 2 total → \(\ProbHat{A=1|L=0} = 0.5\)
  • Older (\(L=1\)): 2 quit out of 4 total → \(\ProbHat{A=1|L=1} = 0.5\)

Step 3: Calculate Nonstabilized IP Weights

For each person: \(W^A_i = 1/\ProbHat{A=A_i|L=L_i}\)

Person \(L\) \(A\) \(\ProbHat{A=A_i\|L=L_i}\) \(W^A_i\)
1 0 0 0.5 2.0
2 0 1 0.5 2.0
3 1 0 0.5 2.0
4 1 0 0.5 2.0
5 1 1 0.5 2.0
6 1 1 0.5 2.0

Step 4: Estimate Causal Effect

Using weighted means in the pseudo-population:

\[ \ProbHatSub{ps}{Y|A=1} = \frac{\sum_{A_i=1} W^A_i Y_i}{\sum_{A_i=1} W^A_i} = \frac{2.0(4) + 2.0(3) + 2.0(5)}{2.0 + 2.0 + 2.0} = \frac{24}{6} = 4.0 \]

\[ \ProbHatSub{ps}{Y|A=0} = \frac{\sum_{A_i=0} W^A_i Y_i}{\sum_{A_i=0} W^A_i} = \frac{2.0(1) + 2.0(2) + 2.0(1)}{2.0 + 2.0 + 2.0} = \frac{8}{6} = 1.33 \]

\[ \text{IP weighted difference} = 4.0 - 1.33 = 2.67 \text{ kg} \]

Step 5: Compare with Standardization

For comparison, let’s calculate the standardized estimate:

\[ \Ehat{Y^{a=1}} = \sum_l \Ehat{Y|A=1, L=l} \ProbHat{L=l} \]

\[ = \Ehat{Y|A=1, L=0} \times 0.33 + \Ehat{Y|A=1, L=1} \times 0.67 \]

\[ = 4.0 \times 0.33 + 4.0 \times 0.67 = 4.0 \]

Similarly, \(\Ehat{Y^{a=0}} = 1.33\).

The standardized and IP weighted estimates agree, as expected!

Step 6: Stabilized Weights

Let’s calculate stabilized weights. First, estimate marginal probabilities:

\[ \ProbHat{A=1} = 3/6 = 0.5 \]

\[ \ProbHat{A=0} = 3/6 = 0.5 \]

Stabilized weights: \(SW^A_i = \ProbHat[A=A_i]/\ProbHat[A=A_i|L=L_i]\)

Person \(\ProbHat[A=A_i]\) \(SW^A_i\)
1 0.5 1.0
2 0.5 1.0
3 0.5 1.0
4 0.5 1.0
5 0.5 1.0
6 0.5 1.0

Since propensity scores equal marginal probabilities, stabilized weights all equal 1, and we get the same causal effect estimate.

Same as before: \(\ProbHat[A=1|L=0] = \ProbHat[A=1|L=1] = 0.5\)

\[ \Ehat{Y^{a=1}} = E{Y|A=1,L=0} \times 0.33 + E{Y|A=1,L=1} \times 0.67 \]

\[ = 5.0 \times 0.33 + 2.5 \times 0.67 = 3.33 \]

Causal effect: \(3.33 - 1.33 = 2.0\) kg, matching IP weighting.

set.seed(12345)
n <- 1500

# Generate baseline confounders
age <- rnorm(n, mean = 43, sd = 12)
age <- pmax(25, pmin(age, 74)) # Constrain to 25-74
sex <- rbinom(n, 1, 0.5) # 1 = female
race <- rbinom(n, 1, 0.15) # 1 = non-white
education <- sample(1:5, n, replace = TRUE, prob = c(0.1, 0.2, 0.3, 0.25, 0.15))
weight_baseline <- rnorm(n, mean = 70 + 5 * sex, sd = 15)
cigarettes_day <- rpois(n, lambda = 20)
years_smoking <- pmax(1, rnorm(n, mean = 25, sd = 8))
exercise <- sample(1:3, n, replace = TRUE, prob = c(0.4, 0.4, 0.2))
activity <- sample(1:3, n, replace = TRUE, prob = c(0.1, 0.8, 0.1))

# Create treatment model (quit smoking)
# Older, more educated, lower baseline smoking more likely to quit
quit_logit <- -2 +
  0.03 * age +
  0.5 * education -
  0.02 * cigarettes_day +
  0.4 * sex -
  0.01 * weight_baseline +
  0.01 * years_smoking
quit_prob <- plogis(quit_logit)
quit <- rbinom(n, 1, quit_prob)

# Create outcome model (weight gain)
# Quitting causes weight gain, but also depends on confounders
weight_gain <- 1 +
  2.5 * quit +
  0.02 * age -
  0.8 * sex +
  0.3 * race +
  0.1 * education +
  0.01 * weight_baseline -
  0.05 * cigarettes_day +
  rnorm(n, mean = 0, sd = 2)

# Combine into dataset
nhefs_sim <- tibble(
  id = 1:n,
  quit = quit,
  weight_gain = weight_gain,
  age = age,
  sex = sex,
  race = race,
  education = education,
  weight_baseline = weight_baseline,
  cigarettes_day = cigarettes_day,

)

# Calculate predicted probabilities
nhefs_sim$ps <- predict(ps_model, type = "response")

# Calculate nonstabilized weights
nhefs_sim$w_unstab <- ifelse(
  nhefs_sim$quit == 1,
  1 / nhefs_sim$ps,
  1 / (1 - nhefs_sim$ps)
)

# Calculate stabilized weights
marginal_prob <- mean(nhefs_sim$quit)
nhefs_sim$w_stab <- ifelse(

# Function to calculate standardized differences
std_diff <- function(x, trt, weights = NULL) {
  if (is.null(weights)) {
    weights <- rep(1, length(x))
  }

  x1 <- x[trt == 1]
  x0 <- x[trt == 0]
  w1 <- weights[trt == 1]
  w0 <- weights[trt == 0]

  mean1 <- weighted.mean(x1, w1)
  mean0 <- weighted.mean(x0, w0)

  var1 <- sum(w1 * (x1 - mean1)^2) / sum(w1)
  var0 <- sum(w0 * (x0 - mean0)^2) / sum(w0)

  (mean1 - mean0) / sqrt((var1 + var0) / 2)
}

6 Common Pitfalls & Checks

Critical Assumption Violations

WarningPositivity Violations

The Problem: When some individuals have propensity scores very close to 0 or 1, corresponding weights become extremely large, leading to unstable estimates.

Detection: - Plot propensity score distributions by treatment group - Check for weights > 10 or in the extreme tails - Look for empty or nearly empty cells when stratifying on confounders

Solutions: - Trimming: Remove individuals with extreme weights - Truncation: Cap propensity scores at reasonable bounds (e.g., [0.05, 0.95]) - Model restriction: Limit analysis to region of sufficient overlap

WarningModel Misspecification

The Problem: Incorrect propensity score model leads to biased estimates even with perfect randomization.

Detection: - Assess covariate balance after weighting - Check model fit diagnostics - Compare results across different model specifications

Prevention: - Include all relevant confounders - Consider nonlinear terms and interactions - Use flexible modeling approaches (e.g., machine learning methods)

WarningUnmeasured Confounding

The Problem: IP weighting only controls for measured confounders. Unmeasured confounding leads to biased estimates.

Assessment: - Conduct sensitivity analyses for unmeasured confounding - Compare with instrumental variable or other approaches - Evaluate biological plausibility of effect size

Mitigation: - Negative control analyses - Multiple comparison groups - Sensitivity analysis frameworks

8 Appendix: Advanced Theory & Derivations

Theoretical Foundation of IP Weighting

Theorem 1: Consistency of IP Weighted Estimators

Under exchangeability \(Y^a \indep A|L\), positivity \(0 < \prob{A=a|L} < 1\), and consistency \(Y = Y^A\) when \(A=a\):

\[ \E{\frac{I(A=a)Y}{f(A|L)}} = \E{Y^a} \]

Proof:

\[ \begin{align} \E{\frac{I(A=a) Y}{f(A|L)}} &= \E{\E{\frac{I(A=a)Y}{f(A|L)}\bigg|L}} \\ &= \E{\frac{\E{I(A=a)Y|L}}{f(A|L)}} \\ &= \E{\frac{E{I(A=a)|L} \cdot \E{Y|A=a,L}}{f(A|L)}} \\ &= \E{\frac{\prob{A=a|L} \cdot \E{Y|A=a,L}}{\prob{A=a|L}}} \\ &= \E{\E{Y|A=a,L}} \\ &= \E{\E{Y^a|A=a,L}} \quad \text{(by consistency)} \\ &= \E{\E{Y^a|L}} \quad \text{(by exchangeability)} \\ &= \E{Y^a} \end{align} \]

Corollary: Stabilized Weights Preserve Expectations

For stabilized weights \(SW^A = f(A)/f(A|L)\):

\[ \E{\frac{f(A)I(A=a)Y}{f(A|L)}} = f(a) \cdot \E{Y^a} \]

This shows that stabilized weights scale the expectation by the marginal probability, preserving relative comparisons.

Efficiency Theory for Stabilized Weights

Theorem 2: Efficiency of Stabilized Estimators

For the linear MSM \(\E{Y^a} = \beta_0 + \beta_1 a\), the stabilized weight estimator \(\hat{\beta}_1^{SW}\) has asymptotic variance:

\[ \text{Var}(\hat{\beta}_1^{SW}) = \frac{\E{\frac{f(A)}{f(A|L)}(Y - E[Y^A])^2}}{\E{\frac{f(A)}{f(A|L)}(A - \E{A})^2}} \]

compared to the nonstabilized estimator:

\[ \text{Var}(\hat{\beta}_1^{W}) = \frac{\E{\frac{1}{f(A|L)}(Y - \E{Y^A})^2}}{\E{\frac{1}{f(A|L)}(A - \E{A|L})^2}} \]

The stabilized estimator is more efficient when \(\text{Var}(f(A)) < \text{Var}(1)\), which always holds.

Robustness Properties

Double Robustness Connection

While IP weighting is not itself doubly robust, it connects to doubly robust methods. The augmented IP weighted estimator:

\[ \hat{\tau}_{AIPW} = \frac{1}{n}\sum_{i=1}^n \left[\frac{A_i Y_i}{\hat{\pi}_i} - \frac{(1-A_i)Y_i}{1-\hat{\pi}_i} + \frac{A_i - \hat{\pi}_i}{\hat{\pi}_i(1-\hat{\pi}_i)}(\hat{\mu}_1(L_i) - \hat{\mu}_0(L_i))\right] \]

is consistent if either the propensity score model \(\hat{\pi}_i\) or outcome models \(\hat{\mu}_a(L_i)\) are correct.

Extensions to Complex Settings

Time-Varying Treatments

For treatments \(\bar{A}_t = (A_0, A_1, \ldots, A_t)\) and time-varying confounders \(\bar{L}_t\):

\[ SW_i^{\bar{A}_t} = \prod_{j=0}^t \frac{f(A_{ij}|\bar{A}_{i,j-1}, \bar{L}_{i,j-1})}{f(A_{ij}|\bar{A}_{i,j-1}, \bar{L}_{ij})} \]

This requires the sequential exchangeability assumption: \(Y^{\bar{a}_t} \indep A_t | \bar{A}_{t-1}, \bar{L}_t\)

Continuous Treatments with Flexible Densities

For continuous \(A\) with unknown density, consider the kernel density estimator:

\(\hat{f}(a|L) = \frac{1}{nh} \sum_{i=1}^n K\left(\frac{a - A_i}{h}\right) \mathbf{1}(L_i \in \mathcal{N}(L))\)

where \(K\) is a kernel function and \(\mathcal{N}(L)\) is a neighborhood of \(L\).

Bandwidth Selection: Use cross-validation to choose \(h\): \(h^* = \arg\min_h \sum_{i=1}^n \left[\log \hat{f}_{-i}(A_i|L_i)\right]\)

where \(\hat{f}_{-i}\) is the leave-one-out density estimator.

simulate_quadratic_msm <- function(n = 1000) {
  L <- rnorm(n)
  A <- rbinom(n, 1, plogis(0.5 * L))

Formal Connection to Causal Graphs

Backdoor Criterion and IP Weighting

Theorem 3: If \(L\) satisfies the backdoor criterion for estimating the causal effect of \(A\) on \(Y\), then IP weighting with weights \(W^A = 1/\prob[A|L]\) yields a consistent estimate of \(E[Y^a]\).

Proof Sketch: The backdoor criterion ensures that conditioning on \(L\) blocks all non-causal paths from \(A\) to \(Y\). IP weighting creates a pseudo-population where \(A \indep L\), effectively “closing” these backdoor paths while preserving the causal path \(A \to Y\).

Front-Door Formula Connection

When direct confounding is unmeasured but a mediator \(M\) is available, the front-door formula provides an alternative:

\[ \E{Y^a} = \sum_m \E{Y|A=a', M=m} \prob{M=m|A=a} \]

This can be implemented using sequential IP weighting:

  1. Weight by \(1/\prob{M|A, L}\) to estimate \(\prob{M^a}\)
  2. Weight by \(1/\prob{A|M, L}\) to estimate \(\E{Y^{a',m}}\)

Sensitivity Analysis Framework

Rosenbaum’s Sensitivity Analysis for IP Weighting

Assume unmeasured confounder \(U\) affects both treatment and outcome:

  • \(\text{logit } \prob{A=1|L, U} = \alpha^T L + \gamma U\)
  • \(\E{Y|A, L, U} = \beta_0 + \beta_1 A + \beta_2^T L + \beta_3 U\)

The sensitivity parameter \(\Gamma = e^{\gamma}\) represents the maximum odds ratio between treatment probabilities for individuals with the same \(L\) but different \(U\).

Bounds Calculation: For treatment effect \(\tau\), the bounds under sensitivity parameter \(\Gamma\) are:

\[ \tau^-(\Gamma) \leq \tau \leq \tau^+(\Gamma) \tag{5}\]

where bounds are computed by solving constrained optimization problems.

Numerical Example

sensitivity_bound <- function(tau_obs, Gamma) {
  # Simplified bound calculation (full version requires optimization)

  tau_upper <- tau_obs + 1.96 * se_obs * variance_inflation

}
